# Лабораторна робота 3.4 — варіант 3

**Тема:** Створення та використання делегатів, подій та лямбда-виразів.

## Вміст
- `Program.cs` — повна реалізація завдання.
- `Контрольні_питання.md` — відповіді на всі 13 контрольних запитань.
- `Variant3OOP.csproj` — проєкт .NET 8.

## Запуск
Потрібен встановлений .NET 8 SDK. У терміналі з цієї папки виконайте:

```bash
dotnet run
```

## Що демонструє програма
1. Зчитує рядок і символ, знаходить індекс першого входження символу через делегат.
2. Виконує ту саму операцію звичайним методом, анонімним методом і лямбда-виразом.
3. Створює стек із місткістю 3.
4. При спробі додати четвертий елемент генерує подію переповнення.
5. Обробник події отримує відправника та аргументи події.
6. Демонструє видалення елемента, повторне додавання та скасування підписки.
